# ENCORE

ENCORE is a text-based adventure game I created as the main project for my introductory Python programming course at Southern New Hampshire University.

This is my first major programming project. I am still early in learning Python and software development, and this project gave me the opportunity to combine the programming concepts I learned throughout the course into one complete game.

## About the Game

Five years after the Tattletale murders, the town of Mareshell hosts the world premiere of *Staring U.* The player takes the role of a theater employee trying to navigate the building, collect the items needed to escape, and uncover hidden evidence before it is too late.

The player's progress and the evidence they discover can lead to different outcomes.

## Features

- Room-based navigation
- Player commands and user input
- Inventory system
- Collectible items and hidden evidence
- Score tracking
- Multiple game outcomes
- Item requirements that affect player progression
- Unlockable story content

## What I Used

- Python
- PyCharm
- Functions
- Conditional statements
- Loops
- Lists
- Dictionaries

## What I Learned

This project helped me practice combining individual Python concepts into a larger program. I gained more experience with organizing game logic, working with dictionaries and lists, handling player input, debugging problems, and thinking through how different parts of a program work together.

I learn best by putting concepts into practice, so building ENCORE helped me understand Python more than working with individual exercises alone.
